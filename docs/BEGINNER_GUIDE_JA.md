# Mandelbrot Formula Explorer 初心者ガイド

最終確認日: 2026-10-22（現在の画面と実装に基づく）

## 1. このツールは何をするもの？

Mandelbrot Formula Explorer は、**フラクタル**と呼ばれる図形を画面に描き、拡大しながら観察できるツールです。  
フラクタルは、ざっくり言うと次のような特徴を持つ図形です。

- 拡大しても似た模様が何度も現れる
- 数式から作れる
- 境界や模様がとても複雑

このツールでは特に次のような楽しみ方ができます。

- **マンデルブロ集合**を見る
- **ジュリア集合**を見る
- 数式を変えて**オリジナルのフラクタル**を作る
- **Buddhabrot** で軌跡を重ねた光の模様を見る
- 気に入った場所への拡大を**アニメーション**で再生する

数学が苦手でも大丈夫です。最初は「不思議な模様を拡大して遊ぶ画像ツール」と考えれば十分です。

## 2. 最初に知っておくと楽な言葉

### フラクタル

細かく見ても、全体と似た雰囲気の模様が繰り返し現れる図形です。

### マンデルブロ集合

フラクタルの代表例です。黒い本体の周りに、色付きの複雑な境界が広がります。

### ジュリア集合

マンデルブロ集合と親戚のような図形です。マンデルブロ集合上のある点をもとにして、別の形のフラクタルを描きます。  
見た目の感覚としては、「マンデルブロ集合が設定画面」だとすると、ジュリア集合は「その設定で生成される別の模様」です。

### 反復

同じ計算を何度も繰り返すことです。フラクタルはこの繰り返し計算で作られます。

### 軌跡

フラクタルでは、ある 1 つの点に対して、同じ計算を何回も繰り返します。  
そのたびに値が少しずつ変わり、「1回目はここ」「2回目はここ」「3回目はここ」というふうに点が移動していきます。  
この、計算のたびに点がたどる道すじを**軌跡**と呼びます。  
難しく考えなくて大丈夫で、「計算するたびに点が動いていくルート」だと思えば十分です。

### 発散

繰り返し計算をしているうちに、値がどんどん大きくなって、中心から遠くへ飛び去っていくことです。  
このガイドでは、「その点は落ち着かず、外へ外へと離れていく状態」と考えてください。

### Zoom

拡大率です。大きいほど深く拡大しています。

## 3. まずはここだけ触れば楽しめる

最初は次の 5 つだけで十分です。

1. `Fractal Type`
2. `Max iterations`
3. `Palette`
4. マウスホイールで拡大・縮小
5. ドラッグで移動

迷ったら次の設定から始めてください。

- `Fractal Type`: 標準のマンデルブロ系プリセット
- `Max iterations`: `1000`
- `Palette`: 好きな色
- `Smooth`: ON
- `Supersampling`: `OFF`

## 4. 使い始める手順

### ローカルで開く場合

リポジトリのフォルダで次を実行し、ブラウザで `http://localhost:3030` を開きます。

```bash
node server.js
```

JavaScript モジュール、BigInt、Web Workers に対応したブラウザを使ってください。通常の描画は CPU でも利用できます。GPU 描画やアニメーションには、WebGPU に対応した環境が必要です。

### 画面の見方

- 左側（または中央）の大きな領域: フラクタル画像
- 右側（または下部）の設定パネル: 描画条件や色、表示方法の調整
- `Julia Set` が ON のとき: 元のフラクタル表示に加えて Julia の画像を表示。全画面表示やモバイルでは、設定内の小さな `Fractal View` が元のフラクタル表示になる

設定パネルは開閉ボタンで隠したり表示したりできます。`Fullscreen` は全画面表示の切り替えです。

## 5. 基本操作

### 拡大・縮小

- **マウスホイール**: 拡大・縮小
- **タッチ操作**: ピンチで拡大・縮小

### 移動

- **ドラッグ**: 表示位置をずらす

### 全体をやり直す

- `Reset All Settings`: 選択中の Fractal Type は維持し、そのほかの設定を初期状態に戻す。Orbit Trap のアップロード画像も消去する
- `Reset Coordinates`: 位置と拡大率だけ初期状態に戻す

### URL で設定を保存・共有

設定変更はアドレスバーの URL に反映されます。この URL をブックマークするかコピーすると、GPU・Hi DPI・Supersampling、軌道・グリッド・Details、Julia の表示と位置・拡大率、Buddhabrot、Animation、Orbit Trap の各設定を復元できます。Orbit Trap にアップロードした画像は URL へ保存しません。Continuous の Samples は、表示中の累計ではなく有限描画用の設定値を保存します。描画結果や準備済みの Animation フレームも保存せず、Buddhabrot の View がオンなら読み込み後に再描画します。

### 画像保存

- `Save Image`: フラクタル画像を PNG で保存
- Julia 表示中は、元のフラクタルと Julia を別々の PNG で保存
- `Orbit` を有効にして固定した軌跡も画像に含まれる。設定パネルや Details のポップアップを含む画面全体のスクリーンショットではない

## 6. まずはこう遊ぶのがおすすめ

### おすすめ手順 1: 眺める

1. そのまま表示する
2. マウスホイールで境界付近を拡大する
3. 色が気に入らなければ `Palette` を変える

### おすすめ手順 2: 模様をくっきりさせる

1. `Max iterations` を少し増やす
2. `Smooth` を ON にする
3. 必要なら `Supersampling` を `2x2` にする

### おすすめ手順 3: 別の世界を見る

1. `Julia Set` を ON にする
2. 見た目の違いを観察する
3. 元のフラクタル表示をドラッグし、中心点を変えて Julia の変化を見る
4. Julia の位置・拡大率は `Julia Set` 横の `↺` でリセットする。Julia 表示を閉じるときは `Julia Set` を OFF にする

## 7. 各設定の意味

### `Fractal Type`

描くフラクタルの種類やプリセットを選びます。

- 何を選べばよいか分からないとき: まずは標準的なマンデルブロ系
- 変わった模様を見たいとき: 別プリセットに切り替える

### `Julia Set`

ジュリア集合モードです。

- OFF: 元のフラクタルだけを見る
- ON: 元のフラクタルの**中心座標を定数 `c` として**、Julia も表示する

元のフラクタルを移動すると、中心座標に合わせて Julia の形が変わります。Julia の画像自体もドラッグやホイール、ピンチで移動・拡大できます。`Julia Set` 横の `↺` は Julia の表示位置を原点、Zoom を `1` に戻します。Julia を閉じる操作はスイッチの OFF です。

マンデルブロ集合は「点を探す側」、ジュリア集合は「その点を使って別の模様を見る側」と考えると、役割の違いが分かりやすいです。  
初心者はまず OFF のままで、慣れてきたら ON にして「同じ数式でもこんなに違う形になるのか」を見るのがおすすめです。

### `Iteration Function`

どんな計算を繰り返してフラクタルを作るかを決める数式です。 
初期値は `z*z + c` で、これは非常に基本的な形です。  
最初は**ここを触らなくて大丈夫**です。ここを変えると、フラクタルの性格そのものが変わり、かなり別物の模様になります。

例:

- `z*z + c`: 基本形
- `sin(z) + c`: 波っぽい複雑な模様

入力後に Enter を押すと反映されます。`How to use the iteration function` から、使える記号・関数・例を確認できます。`z` は現在の値、`c` は各点の座標（Julia では固定した定数）、`i` は虚数単位、`n` は反復番号です。過去の値を参照する `zAt(k)`、`zDelay(k)` も使えますが、GPU で使える `k` は固定の非負整数です。

### `z0`

反復計算の出発点です。  
実部と虚部の 2 つの入力欄で指定します。標準の Mandelbrot では両方 `0` のままで大丈夫です。プリセットによっては別の値が設定されます。

### `Max iterations`

画面の各ピクセルについて、最大何回まで繰り返し計算するかです。  
ここでいうピクセルは、画面を構成している小さな点 1 つのことです。フラクタルは、その点ごとに「この場所はどんな振る舞いをするか」を計算して色を付けています。

- 小さい値: 早く表示できるが、境界の細かい模様を十分に描ききれず、少し大ざっぱな見た目になりやすい
- 大きい値: 表示に時間はかかるが、境界の細かい模様まで描きやすくなり、より密で精細な見た目になりやすい

目安:

- 軽く試す: `300` から `1000`
- 深く拡大する: `2000` 以上

### `Palette`

色の付け方です。図形そのものの形は変わらず、見た目だけが変わります。  
「構造はそのまま、雰囲気だけを変えたい」ときに使う項目です。

### `Palette density`

色の変化の細かさです。

一般に値を大きくすると色の縞が細かくなります。数値欄にはスライダーの範囲外や負の値も入力できます。一部のパレット（Stripe、Grid、Orbit Trap）では、この設定による色の変化はありません。

### `Palette rotation`

使う色の開始位置をずらします。模様は同じで、色だけが回転したように変わります。

### `Fractal GPU`

対応環境なら GPU を使って高速化します。

- ON: 速くなることが多い
- OFF: CPU で描画

WebGPU が使えない環境や GPU に対応しない設定では CPU 描画を利用します。うまく表示されない場合は OFF も試してください。`Buddhabrot GPU` は別のスイッチです。

### `Hi DPI`

高解像度ディスプレイ向けに、より細かいピクセルで描きます。

- ON: きれいだが重くなることがある
- OFF: 軽い

### `Smooth`

色の境目をなめらかに見せます。初心者には ON がおすすめです。  
ON にすると、色の段差が目立ちにくくなり、より自然なグラデーションに見えやすくなります。

### `Escape R`

点が「発散した」とみなす基準です。通常は初期値のままで大丈夫です。  
初期値は `4` です。値を変更すると `Smooth` が自動で OFF になります。必要なら変更後に ON に戻せます。

この値は主に**カスタム数式を試すときの上級者向け設定**です。

### `Grid`

座標の目盛りをフラクタル画像の上に表示します。  
実数軸と虚数軸、そして現在の拡大率に合った目盛りが表示されるので、どのあたりを見ているのかを把握しやすくなります。  
通常は OFF で、座標を確認したいときだけ ON にすると画面が見やすいです。

### `Orbit`

マウスを置いた点が、計算の中でどう動くかを線や点で表示します。  
つまり、その点の**軌跡**を見せてくれる機能です。  
フラクタルの「中で何が起きているか」を視覚的に理解したいときに便利です。  
`Gradient` を ON にすると、Orbit の点が計算の進み具合に合わせて黄色から赤へ変化します。  
どの点が最初のほうで、どの点が後のほうなのかを色で追いやすくなるため、軌跡の流れを見たいときに便利です。

`Mode` は `Lines+Dots`（線と点）、`Lines`（線だけ）、`Dots`（点だけ）から選べます。

動かさずにクリック、または 1 本指でタップすると軌跡を固定できます。固定した点のマーカーをもう一度クリック／タップすると解除します。ドラッグやピンチでは固定状態は切り替わりません。Julia や Buddhabrot の表示でも使えます。

`Gradient` は Orbit 表示用の見え方を変える設定で、後述の `Orbit Trap` とは別の機能です。

### `Details`

表示の**中心点**について、座標や反復計算の情報を表示します。マウス位置を追う表示ではありません。極端な拡大など、軌跡を信頼して計算できない条件では表示されない場合があります。

### `Supersampling`

1 ピクセルを複数回計算して、ギザギザを減らします。

- `OFF`: 最速
- `2x2`: 初心者にちょうどよい
- `4x4` 以上: かなり重くなることがある

## 8. 座標入力とは？

下部にある `X (Real)`, `Y (Imaginary)`, `Zoom` は、今見ている場所を数値で直接指定する機能です。

- `X`: 横方向の位置
- `Y`: 縦方向の位置
- `Zoom`: 拡大率

これは次のようなときに使います。

- 以前見つけた場所に正確に戻りたい
- 他の人から教わった座標へ一発で移動したい
- 同じ場所を再現したい

入力した値は `Apply Coordinates` で反映します。`Zoom` は `4.70e3` のような指数表記も使えます。`Reset Coordinates` は選択中のプリセットの初期位置・拡大率へ戻します。

分からないうちは、無理に使わなくて大丈夫です。

## 9. Buddhabrot とは？

`Buddhabrot` は、通常のマンデルブロ表示とは少し違う描き方です。  
点そのものではなく、**軌跡**をたくさん重ねて絵にします。

普通のマンデルブロ表示では、「その点が何回目で外へ飛び出したか」を見て、その場に色を塗ります。  
一方 Buddhabrot では、「その点が計算の途中でどんな道すじを通ったか」を記録し、その道すじをたくさん重ねて光の模様として描きます。

そのため、普通の表示よりも次の特徴があります。

- 写真的・星雲的な見た目になりやすい
- きれいだが時間がかかる
- 試行回数を増やすほど画質が上がる

### 初心者向けの使い方

1. `Continuous` を OFF にし、`Samples` を設定する（初期値は `3000000`。まずは小さくして試してもよい）
2. `Render Buddhabrot` を押す。Julia 表示中は Julia の Buddhabrot を描く
3. 表示が暗ければ `Buddhabrot Brightness` と `Buddhabrot Gamma` で調整する
4. 途中で止めたいときは `Stop` を押す。途中までの画像は残る

### 主な項目

| 項目 | 役割 |
| --- | --- |
| `View` | 描画済みの Buddhabrot と通常表示を切り替える。描画前は使えない |
| `Samples` | 試す軌跡の数。多くするとノイズを減らしやすいが時間がかかる |
| `Continuous` | 上限を決めず、Stop まで軌跡を追加し続ける。初期値は OFF |
| `Buddhabrot GPU` | Buddhabrot の計算に GPU を使う |
| `Palette` | Buddhabrot 専用の色。`Preset-01`〜`Preset-05` から選ぶ。通常描画の Palette とは別 |
| `Buddhabrot Mode` | 発散する軌跡／発散しない軌跡のどちらを集めるか |
| `Band Mode` | `perTrajectory` は軌跡全体を軌跡の長さに応じた同じ色帯で、`perPoint` は各点を反復の進み具合に応じた色帯で描く。初期値は `perTrajectory` |
| `Sampling Range` | ランダムな出発座標を選ぶ範囲。下記参照 |
| `Buddhabrot Brightness` | 全体の明るさ。範囲 `1.0`〜`3.0`、初期値 `1.2` |
| `Buddhabrot Gamma` | 暗い部分の見え方。範囲 `0.3`〜`20`、初期値 `4.8` |
| `Points per Batch (CPU)` | 全ワーカー合計で同時に進める軌跡の数。最小 `1`、初期値 `64`。有限描画では Samples と `1024` の小さい方が上限、Continuous では `1024` が上限。Render Slowdown が 0 より大きいときに有効 |
| `Render Slowdown (CPU)` | 軌跡をゆっくり鑑賞するための調整。`0` は最速。大きくすると遅くなるが、数値はミリ秒などの時間ではない |

CPU 用の 2 つのスライダーは、操作や個別リセットをすると `Buddhabrot GPU` が OFF になります。Points per Batch を増やしても、1 本の軌跡は更新ごとに 1 ステップずつ進みます。

CPU・GPU とも、軌跡は脱出または `Max iterations` まで描画します。同じ画素に重なっても表示上の収束で打ち切らないため、同じ seed で拡大したときの細かな動きや、後半のパレット色も残ります。長い非発散軌跡は描画時間が増えることがあります。

### `Sampling Range` の違い

- `Current View`（初期値）: 現在の表示範囲からランダム座標を選ぶ
- `Initial View`: 式・初期値 z0・Escape Radius からサンプリングする円を自動設定し、その内部から面積に対して一様にランダム座標を選ぶ。初回の反復が `z₁ = a*c + b` と求められる場合、中心は `−b/a`、半径は `Escape Radius / |a|`。求められない場合は原点中心・半径 `4` にフォールバックする。Julia では原点中心・半径 Escape Radius の円から初期値 z0 を選ぶ。表示位置・拡大率・画面の縦横比には依存せず、Fixed Samples が ON の間は決定した円と seed を固定する

どちらも**軌跡は現在の表示範囲に描画**され、CPU・GPU の両方で使えます。`Initial View` から深い拡大先を見ると、そこへ入る軌跡が少なくなることがあるため、Samples を増やすか Continuous を試してください。

### 連続して描き込みたいとき

`Continuous` を ON にして描画すると、Stop までサンプルを蓄積します。Samples は編集できなくなり、計算済みの累計を表示します。OFF に戻すと、以前の有限描画用 Samples が戻ります。

通常の最速描画では CPU はおおむね 100 ms ごと、GPU の連続描画はおおむね 1 秒ごとに画像を更新します。Samples の累計表示はおおむね 500 ms ごとに更新されます。CPU の Slowdown 設定時は、その速度に応じた更新です。

有限描画の `Render time` は完了時に、連続描画では Stop 時に経過時間を表示します。Julia Buddhabrot も同じ欄を使います。

### 設定を変えたときの動作

Buddhabrot が表示中なら、完了後・Stop 後も含めて次のように動きます。

- Buddhabrot の `Palette`、`Buddhabrot Mode`、`Band Mode`、`Sampling Range` の変更: 即座に新しく描画する
- `Buddhabrot GPU`、`Continuous` の切り替え: 即座に新しい実行方法で描画する
- `Samples` の変更: 現在の描画をやり直さない。次の Render や移動・拡大時に反映される
- Brightness、Gamma の変更: 蓄積済みの軌跡の見え方を調整する

通常のフラクタルを表示しているときは、これらの設定変更だけで Buddhabrot が開始されることはありません。Render や移動・拡大、再描画を伴う設定変更では蓄積を最初から始めます。Stop は現在の画像を止める操作で、続きからの再開ではありません。

### Buddhabrot を移動・拡大する

描画中・描画済み・Stop 後の Buddhabrot は、ドラッグ、ホイール、トラックパッド、2 本指のピンチで移動・拡大できます。操作中も更新し、操作が終わると最終位置を描画します。この操作は常に有効で、専用スイッチはありません。

有限描画の操作中も Samples、解像度、Supersampling、Max iterations、CPU の Slowdown・Points per Batch は設定どおりです。高品質な設定では表示が追いつくまで時間がかかる場合があります。

Julia Buddhabrot 表示中に元の `Fractal View` を移動すると、新しい中心座標を使って Julia Buddhabrot を更新します。通常の Julia 描画へは戻りません。

### `Buddhabrot Mode` の違い

#### `Buddhabrot`

通常版です。  
発散して外へ飛び出していく点の軌跡を集めて描きます。  
Buddhabrot らしい、光が流れるような見た目になりやすく、まずはこちらから試すのがおすすめです。

#### `Anti-Buddhabrot`

通常版とは逆の見方をするモードです。  
発散する点ではなく、**Max iterations まで発散しなかった点の側**に注目した表現になります。\
そのため、通常の Buddhabrot とは雰囲気の違う、少し反転したような独特の絵になりやすいです。

「同じ場所でも見え方がどう変わるか」を比べて楽しむモードだと思うと分かりやすいです。  
最初は通常の `Buddhabrot` を見てから切り替えると、違いをつかみやすいです。

### `Gamma` を感覚的に言うと

`Brightness` が画像全体をまとめて明るくしたり暗くしたりするつまみだとすると、`Gamma` は**暗い部分をどれだけ見えやすくするか**を調整するつまみです。

- 下げる: 暗い部分の細かな軌跡が見えやすくなり、全体が明るくなる
- 上げる: 明るい部分とのメリハリが強くなりやすい

「全体は暗すぎないのに、細い軌跡が埋もれて見えない」ときに調整すると効果が分かりやすいです。

## 10. Orbit Trap とは？

`Orbit Trap` は、計算中の軌跡が特定の形にどれだけ近づいたかを使って着色する方法です。

ここでも見るのは「計算の途中で点がどんな道すじを通ったか」です。  
ただし Buddhabrot のように軌跡そのものを光らせるのではなく、軌跡が特定の形にどれくらい近づいたかを使って色を決めます。  
難しく見えますが、感覚としては次の理解で大丈夫です。

- 通常の色付け: 「何回で外に飛び出したか」で色を決める
- Orbit Trap: 「計算の軌跡が、どんな形に近づいたか」で色を決める

そのため、普通のパレットとはかなり違うアート寄りの表現ができます。  
通常描画用の `Palette` で `Orbit Trap` を選ぶと設定パネルが現れます。初心者はまず後回しで構いません。慣れてきたら次を試してください。

- `Shape`: `Circle (Ring)` や `Cross`
- `Mode`: `Distance Closest`
- `Size`: 少しずつ変更

また、`Shape` で `Bitmap Image` を選ぶと、**自分の好きな画像を Orbit Trap に使う**こともできます。\
PNG や JPEG の画像を読み込んで、画像の形や濃淡をもとにした、かなり個性的な着色表現を作れます。

## 11. Animation で拡大を再生する

`Animation` は、初期表示から指定した場所へ移動・拡大する映像を、事前に描画してから再生する機能です。

1. 目的の座標と Zoom を入力し、`Apply Coordinates` で適用する。入力しただけの値は使われない
2. 通常のフラクタル表示で `Animation` を ON にする
3. `Zoom speed`（拡大の速さ）、`Frame rate`（1 秒あたりのコマ数）を選ぶ
4. `Prepare` を押し、全コマの準備が `100%` になるまで待つ
5. `Play` を押す。初期表示から目的地へ移動し、拡大する

準備・再生中は Play のボタンが `Stop` に変わります。Stop は準備を中止するか、再生をその場で止めます。準備済みの映像を再び Play すると、先頭から再生します。

### 自動で細かさを調整する

`Auto adjust iterations & density` は初期値 OFF です。ON にすると、移動・拡大の経路に応じて反復回数とパレット密度を調整し、最後は目的地の設定値に合わせます。

`Minimum iterations` が空なら `1000` を使い、上限は目的地の Max iterations です。最小値が目的地の値以上なら、反復回数は目的地の値で一定になります。見た目を近づけるための調整なので、途中の細部や色の印象が完全に同じになる保証はありません。

### 利用条件と再準備

WebGPU と、ブラウザの一時保存機能（OPFS・Web Locks）が必要です。Fractal GPU は自動で ON になり、アニメーションは CPU 描画へ切り替わりません。Julia モードや GPU 非対応の設定では準備できません。アニメーションの対象は通常のフラクタル描画です。Buddhabrot を表示していても映像は通常描画になり、再生開始時に Buddhabrot は停止・解除されます。

座標、描画設定、速度、フレームレート、キャンバスの大きさなどを変更すると再準備が必要です。高解像度や長い経路では一時保存容量も増えます。容量不足の場合は、解像度やコマ数、経路を見直してください。この機能は画面内での再生用で、動画ファイルを書き出すボタンはありません。

## 12. 重い・遅いときの対処

描画が重いときは、次の順で試すと効果が出やすいです。

1. `Supersampling` を `OFF` にする
2. `Max iterations` を下げる
3. `Hi DPI` を OFF にする
4. `Fractal GPU` または `Buddhabrot GPU` を ON/OFF 切り替えて比べる
5. Buddhabrot なら `Render Slowdown (CPU)` を `0` にし、有限描画の `Samples` を減らして Render し直す。連続描画を終えたいときは `Stop` を押す

## 13. 初心者におすすめの触り方

### まず 10 分で楽しむなら

1. 何も変えずにホイールで拡大する
2. `Palette` を変える
3. `Smooth` を ON にする
4. `Max iterations` を `1000` から `2000` にする
5. 気に入った場所を `Save Image` で保存する

### 少し慣れたら

1. `Julia Set` を試す
2. `Iteration Function` を別の式にする
3. `Orbit` で軌跡を見る
4. `Buddhabrot` を描いてみる

## 14. よくある疑問

### 黒い部分は何？

多くの場合、発散せず内部に残る領域です。マンデルブロ集合の本体だと思ってください。

### 色が変わるのはなぜ？

多くの場合、「何回目で外へ飛び出したか」や「どんな軌跡を通ったか」を色に変換しているからです。  
つまり、色は単なる飾りではなく、「その場所で計算がどう振る舞ったか」を見やすくしたものです。

### Julia Set はいつ使えばいいの？

マンデルブロ集合を見ていて「この場所を元にすると、別のフラクタルはどんな形になるのだろう」と試したくなったときです。  
最初はマンデルブロ集合だけで十分ですが、慣れてくると Julia Set は「同じルールから生まれる別の世界を見る機能」として楽しくなります。

### 拡大しても終わりがないの？

マンデルブロ集合は非常に細かい構造を持つため、かなり深くまで拡大しても新しい模様が現れます。

### 数式を変えたら壊れたように見える

珍しい式では、発散条件や色付けが合わず、真っ黒・真っ白・ノイズ状になることがあります。  
その場合は次を試してください。

- `z0` を変更する
- `Max iterations` を増やす

`z0` が `0` のままだと、反復計算の出発点が原点に固定されます。数式によっては、そこから計算を始めると多くの点がほとんど同じように動いたり、すぐに同じ値へ落ち着いたりして、色の差が出ず真っ黒に見えることがあります。  
`z0` を `0` 以外に変えると、計算の出発点が少しずれます。すると、それまで似た動きしかしていなかった点の軌跡や発散の仕方に差が出て、黒一色ではなく模様として描画されるケースが多くあります。

### Buddhabrot が暗い／ほとんど見えない

Brightness を上げ、Gamma を下げてみてください。選んだパレットには黒い色帯もあります。表示範囲を変える、Samples を増やす、Continuous で描き込む、といった方法でも変わります。Anti-Buddhabrot では、Max iterations まで発散しない軌跡が少ない場所は暗くなります。

### キーボードでも操作できる？

入力欄や選択欄を編集中でなければ、次のショートカットが使えます。

| キー | 操作 |
| --- | --- |
| `f` | 全画面表示の切り替え |
| `b` | Render Buddhabrot |
| `s` | Smooth の切り替え |
| `+` または `=` | Max iterations を 100 増やす |
| `-` | Max iterations を 100 減らす |
| `Backspace` | Reset All Settings |
